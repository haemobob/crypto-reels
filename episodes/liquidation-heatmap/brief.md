# Visual brief — Peta likuidasi Bitcoin

- **Framework**: Remotion. The reference's clone workflow (Hypit) was used for analysis only (download, transcript, frames); no generated media was needed, so the build stays in the brand system.
- **Visual subject**: the liquidation heatmap itself: today's real CoinGlass map, then a Cryptonite rebuild of what it aggregates.
- **Visual concept**: *the map is made of other people's exits.* Single positions drop liquidation ticks; ticks stack into the bands; price runs into a band and speeds up; your own line is moved out of it.
- **Different from recent episodes** (`reference/episode-visual-log.md`): no candles or side-by-side panels (btc-mirip-2023); a real UI screenshot window as the anchor; a horizontal-band ladder with time running left to right; hero move follows a falling price into a band; one polarity flip.
- **Opening asset hierarchy**: level 3 (real interface screenshot, unaltered crop, CoinGlass watermark kept).
- **Colour exception**: yellow is used only for the dense bands, because the real tool and the narration call them "zona kuning". Blue stays dominant; red only for forced selling and the wrong liquidation line.
- **Polarity**: black throughout; off-white for the caveat ("PERKIRAAN, BUKAN KEPASTIAN"), the pivot from mechanism to limits.
- **Hero move**: push-in following the price dot from $84.2K into the $82.3K band and through it (28.7–37 s); pull back for the sweep and the check.
- **Left out from the reference**: talking head, the exchange sponsorship, "comment YES" CTA, price targets.
