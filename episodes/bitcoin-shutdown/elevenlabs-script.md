**Model:** Eleven v3. **Voice:** Ongky Himawan – Calm, Deep (the same voice as the last two episodes). **Stability:** Natural. If a part comes out flat, regenerate only that part on Creative.

Generate the **7 parts separately** and send all 7 files. Name them `part1` … `part7`; MP3 or WAV both work. **Part 1 — Hook (urgent, sharp)**
```
[urgent] [slightly alarmed] BITCOIN akan segera... SHUTDOWN?
```

**Part 2 — News (serious, authoritative)**
```
[serious] [authoritative] Pemerintah Inggris baru saja mengimbau warganya bersiap menghadapi tiga hari gangguan layanan penting, seperti listrik dan internet.
```

**Part 3 — Escalation (calm first, then short and urgent)**
```
[calm] Ini bukan berarti internet dunia akan segera mati.
[lowers voice] Tapi bayangin... kalau gangguannya meluas.
[urgent] [clipped] Mesin pembayaran nggak berfungsi. ATM offline. Aplikasi bank... nggak bisa dibuka.
```

**Part 4 — The question (dramatic, slow build)**
```
[slowly] Sekarang pertanyaannya...
[dramatic] kalau INTERNET mati...
[intense] BITCOIN lo GIMANA?
```

**Part 5 — How Bitcoin works (clear, precise, slightly slower)**
```
[clear] [measured] Bitcoin memang nggak punya satu server pusat. Tapi setiap transaksi tetap perlu dikirim ke jaringan komputer, lalu dikonfirmasi.
[concerned] Kalau koneksi internet lo terputus, transaksi bisa tertunda. Dan kalau jaringan global terpecah, komunikasi antar-node juga bisa terganggu.
```

**Part 6 — The reveal (assertive turn, then calm)**
```
[whispers] Tapi tunggu...
[firm] [confident] Bitcoin lo nggak otomatis HILANG.

[intrigued] Bahkan, ada satelit yang bisa menyiarkan data blockchain tanpa internet biasa.
[matter-of-fact] Meski untuk mengirim transaksi, tetap diperlukan jalur komunikasi lain.
```

**Part 7 — Ending (slower, quiet, unsettling)**
```
[skeptical] Dan kalau Bitcoin lo disimpan di exchange?
[serious] Aksesnya juga bergantung pada sistem mereka.
[thoughtful] Jadi, internet mati belum tentu membuat Bitcoin mati.
[slowly] [ominous] Tapi kalau seluruh sistem keuangan offline...
[quietly] apa gunanya punya uang...
[quietly] [unsettling] kalau lo nggak bisa menggunakannya?
```
